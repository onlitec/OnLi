# Roadmap do Módulo de Configuração de Layout

1. **Estrutura Inicial**
   - Criar módulo em `custom/layoutconfig`
   - Definir constantes e tabelas necessárias.
2. **Protótipo de UI**
   - Implementar color picker + preview em tempo real.
   - Testar sliders e inputs de dimensão.
3. **Armazenamento**
   - Escolher abordagem (BD, arquivo, JSON).
   - Criar API AJAX para CRUD de configurações.
4. **Presets de Skins**
   - Definir formatos de presets (JSON).
   - Implementar import/export de presets.
5. **Histórico e Rollback**
   - Armazenar versões anteriores.
   - Permitir restauração de configuração.
6. **Permissões e Segurança**
   - Garantir que apenas administradores acessem.
7. **Documentação e Testes**
   - Documentar uso do módulo.
   - Escrever testes unitários e de integração.
8. **Release e Feedback**
   - Liberar versão beta para usuários.
   - Coletar feedback e ajustar UX/UI.
